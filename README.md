# 🔷 C# & .NET — Fundamentos e Programação Orientada a Objetos (POO)

> Repositório dedicado ao estudo, implementação de exercícios e consolidação de boas práticas no ecossistema .NET com foco em desenvolvimento back-end.

---

## 📌 Sobre o Repositório

Este repositório reúne projetos de console, algoritmos e aplicações práticas desenvolvidas em **C#**. O objetivo principal é aprofundar os pilares da Programação Orientada a Objetos, o domínio da tipagem estática e a criação de bases sólidas para o desenvolvimento de APIs e sistemas corporativos.

---

## 🧠 Conceitos e Tópicos Aplicados

* **Fundamentos e Sintaxe:** Tipagem estática forte, operadores, estruturas condicionais (`if/else`, `switch case`) e laços de repetição (`for`, `foreach`, `while`).
* **Pilares de POO:**
  * **Abstração:** Modelagem de entidades do mundo real em classes.
  * **Encapsulamento:** Controle de acesso através de modificadores (`public`, `private`, `protected`) e uso de *Properties* (`get; set;`).
  * **Herança:** Reutilização e extensão de comportamentos entre classes base e derivadas.
  * **Polimorfismo:** Sobrescrita de métodos com `virtual`, `override` e uso de interfaces.
* **Interfaces e Contratos:** Definição de contratos claros para desacoplamento de código.
* **Coleções e LINQ:** Manipulação de dados com `List<T>`, dicionários e consultas com métodos LINQ.
* **Tratamento de Exceções:** Fluxos de segurança com blocos `try`, `catch` e `finally`.
